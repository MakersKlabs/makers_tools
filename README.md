# MakersKlabs Tools

A collection of **separate** tools and applications by **MakersKlabs**.
Each tool lives in its **own repository**, so it can evolve, version and be
released independently.

> 🇮🇹 Versione italiana: [README.it.md](README.it.md)

## Projects

| Project | Description | Repository |
|---|---|---|
| **microscope-app** | Desktop application for Ubuntu (Python + Qt + OpenCV) to capture images and videos from a high-resolution USB microscope. | <https://github.com/MakersKlabs/microscope-app> |
| **microscope-rust** | Retro-styled (1980s CRT) rewrite in Rust, shipped as a small self-contained binary for Linux, Windows and macOS. | <https://github.com/MakersKlabs/microscope-rust> |

## Why separate repositories

- Each project has its own history, issues, releases and CI.
- A tool can be cloned and used on its own, without the others.
- Versioning is independent (a release of one tool does not affect the others).
