# MakersKlabs Tools

Una raccolta di strumenti e applicazioni **separati** di **MakersKlabs**.
Ogni strumento vive nel suo **repository dedicato**, così può evolvere, essere
versionato e pubblicato in modo indipendente.

> 🇬🇧 English version: [README.md](README.md)

## Progetti

| Progetto | Descrizione | Repository |
|---|---|---|
| **microscope-app** | Applicazione desktop per Ubuntu (Python + Qt + OpenCV) per acquisire immagini e video da un microscopio USB ad alta risoluzione. | <https://github.com/MakersKlabs/microscope-app> |
| **microscope-rust** | Riscrittura in Rust in stile terminale anni '80, distribuita come binario autonomo e leggero per Linux, Windows e macOS. | <https://github.com/MakersKlabs/microscope-rust> |

## Perché repository separati

- Ogni progetto ha la sua storia, le sue issue, le sue release e la sua CI.
- Uno strumento può essere clonato e usato da solo, senza gli altri.
- Il versionamento è indipendente (una release di uno strumento non tocca gli altri).
